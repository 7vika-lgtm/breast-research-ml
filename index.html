Can a model tell a malignant mass from a benign one by its cells?

A machine learning study on 569 breast mass samples. We compare five models, tune for the fewest missed cancers, and check which cell measurements drive the answer.

The question

Doctors measure features of cell nuclei from a fine needle sample, such as radius, texture, area and concavity. We ask whether those measurements alone can separate malignant from benign masses, and how to build a model that rarely misses a cancer.

Method

  1. Data. Wisconsin Diagnostic Breast Cancer dataset: 569 samples, 30 numeric features, no missing values.
  2. Explore. Compare feature distributions by diagnosis and map correlations between features.
  3. Split. 80% train, 20% held-out test, stratified by diagnosis.
  4. Compare. Five-fold cross-validation on logistic regression, SVM, KNN, random forest and gradient boosting.
  5. Tune. Grid search on the SVM, scored by recall.
  6. Evaluate. Confusion matrix, ROC curve and threshold analysis on the test set.
  7. Explain. Permutation importance shows which features matter.

Why recall comes first

A false alarm leads to more tests. A missed cancer delays treatment. So we tune for recall, then use the threshold analysis to see how many false alarms we accept to catch more cancers. The slider above shows the same idea.

Limitations

This is an educational project, not a medical device. The dataset is small, comes from one source, and uses pre-extracted features. Results have not been validated on outside data.
